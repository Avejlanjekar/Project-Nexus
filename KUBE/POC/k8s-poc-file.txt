
POC 1 — ConfigMap: Volume Mount + Env Var Reference

1 Create ConfigMap app-config with keys: APP_ENV=production, APP_NAME=inventory-service.
2 Create pod config-inspector (toolbox image), that:
    -mounts app-config as a volume at /etc/app/config
    -also injects APP_ENV as an environment variable via configMapKeyRef
3 Verify:
    -kubectl exec config-inspector -- cat /etc/app/config/APP_ENV
    -kubectl exec config-inspector -- printenv APP_ENV

POC 10 — Capstone: order-service + inventory-service, All Four Resource Types
1 inventory-service pod (Image 2):
    -mounts ConfigMap app-config as a volume at /etc/app/config, and injects APP_ENV as an env var
    -mounts Secret db-credentials as a volume at /etc/app/secrets, and injects DB_USERNAME as an env var
    -runs under ServiceAccount app-sa
    -mounts a PVC at /data
2 ClusterIP Service inventory-service targets port 5678.
3 order-service pod (Image 3) gets INVENTORY_URL=http://inventory-service:5678 from a ConfigMap order-config, injected via configMapKeyRef.
4 From order-service: curl $INVENTORY_URL
5 From inventory-service: write a file to /data, then delete/recreate the inventory-service pod (keeping the Service, ConfigMap, Secret, PVC, and ServiceAccount bindings identical) and re-verify everything.

Expected result:

- curl $INVENTORY_URL from order-service returns a body containing config file APP_ENV: production, secret file username: <username value>, and the APP_ENV/DB_USERNAME env var lines populated.
- ls /var/run/secrets/kubernetes.io/serviceaccount on inventory-service shows the auto-mounted SA token files.
- The file written to /data before deletion is still present after inventory-service is recreated.
- order-service requires no changes after inventory-service is recreated — it only ever referenced the Service name via INVENTORY_URL, never a Pod IP.
- Deliverable: all 3 Dockerfiles + app.py, all YAML files, and the exact kubectl commands + output that prove each requirement above.

avej_lanjekar@AvejLanjekar:~/poc-kuber/inventory-service$ cat app.py
import os
import http.server

CONFIG_DIR = "/etc/app/config"
SECRET_DIR = "/etc/app/secrets"

class Handler(http.server.BaseHTTPRequestHandler):
    def do_GET(self):
        lines = ["INVENTORY SERVICE", "=================="]
        lines.append(f"APP_ENV env var: {os.environ.get('APP_ENV', '<not set>')}")
        lines.append(f"DB_USERNAME env var: {os.environ.get('DB_USERNAME', '<not set>')}")

        if os.path.isdir(CONFIG_DIR):
            for f in sorted(os.listdir(CONFIG_DIR)):
                path = os.path.join(CONFIG_DIR, f)
                if os.path.isfile(path):
                    with open(path) as fh:
                        lines.append(f"config file {f}: {fh.read().strip()}")

        if os.path.isdir(SECRET_DIR):
            for f in sorted(os.listdir(SECRET_DIR)):
                path = os.path.join(SECRET_DIR, f)
                if os.path.isfile(path):
                    with open(path) as fh:
                        lines.append(f"secret file {f}: {fh.read().strip()}")

        body = "\n".join(lines).encode()
        self.send_response(200)
        self.send_header("Content-Type", "text/plain")
        self.end_headers()
        self.wfile.write(body)

http.server.HTTPServer(("0.0.0.0", 5678), Handler).serve_forever()
